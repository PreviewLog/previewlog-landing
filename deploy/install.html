설치 안내

첫 공개 버전은 M1 이상 Apple Silicon Mac을 기준으로 준비하고 있습니다. Windows 버전도 이후 출시할 예정입니다.

MACOS PREPARING · WINDOWS PLANNED
01

시스템 확인

Apple Silicon M1 이상, macOS 13 Ventura 이상, 메모리 8GB 이상을 권장합니다. 앱과 AI 모델을 모두 설치하면 약 2GB가 필요합니다.

02

파일 다운로드

macOS 공개 릴리스에서는 이 사이트에서 DMG를 내려받고, 버전·파일 크기·SHA-256 체크섬을 확인할 수 있습니다.

03

앱 설치

DMG를 열어 Applications 폴더로 이동한 뒤 실행합니다. 공식 설치파일은 Developer ID 서명과 Apple 공증을 거칩니다.

04

첫 실행

로그인 또는 Trial을 시작하고, 모델 관리 화면에서 필요한 Basic 모델을 다운로드합니다. 모델은 다운로드 후 검증됩니다.

Windows 버전 출시 예정

현재 설치 안내는 M1 이상 Mac을 기준으로 합니다. Windows 버전의 지원 사양과 설치 방법은 출시 준비가 완료되면 별도로 안내합니다.

설치 전 알아두기

프로젝트 DB와 캐시는 원본과 분리된 쓰기 가능한 로컬 또는 외장 SSD에 두는 것을 권장합니다. 네트워크 드라이브에 프로젝트 DB를 직접 두는 것은 초기 버전에서 권장하지 않습니다.
