04

첫 실행

로그인 후 체험이나 구독을 시작하고, 모델 관리 화면에서 필요한 모델을 다운로드한 후 분석을 시작합니다.

Windows 버전 출시 예정

현재 설치 안내는 M1 이상 Mac을 기준으로 합니다. Windows 버전의 지원 사양과 설치 방법은 출시 준비가 완료되면 별도로 안내합니다.

설치 전 알아두기

프로젝트 DB와 캐시는 원본과 분리된 쓰기 가능한 로컬 또는 외장 SSD에 두는 것을 권장합니다. 네트워크 드라이브에 프로젝트 DB를 직접 두는 것은 초기 버전에서 권장하지 않습니다.
