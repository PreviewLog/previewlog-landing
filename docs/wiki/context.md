# 프로젝트 맥락 (Context)

## 1. 제품 개요
- **제품명**: PreviewLog (프리뷰로그)
- **정의**: 프록시 영상을 로컬에서 분석해 대표 컷, 한국어 음성 전사, 타임코드, 품질 경고를 정리하고 편집용 프리뷰 자료(HTML, PDF, SRT, CSV)로 내보내는 macOS 데스크톱 애플리케이션
- **슬로건**: "From footage to a workable first draft" / "촬영본 10시간, 처음부터 다 보지 마세요"
- **개발사**: BLDNEX (빌드넥스)
- **공식 서비스 URL**: `https://previewlog.bldnex.com`

## 2. 타겟 고객 및 사용자 문제
- **주요 대상**: 조연출, 프리뷰 작가, 독립 다큐멘터리·인터뷰 영상 제작팀, 기업·교육 영상팀, 데이터 매니저
- **해결하는 핵심 문제**:
  - 촬영이 끝난 후 수십 시간의 원본 영상을 처음부터 끝까지 다 보며 테이크와 대사를 수작업으로 받아 적는 프리뷰 정리 과정의 과도한 시간 낭비 해소
  - 자동 편집기가 아닌, 편집을 준비하는 다음 단계로 전달 가능한 초안을 만드는 도구

## 3. 핵심 비즈니스 및 라이선스 정책 (Single Source of Truth)
- **14일 무료 체험판**:
  - 신용카드나 결제 수단 등록 없이 즉시 시작
  - 14일 경과 후 자동 유료 전환 및 자동 결제 없음
  - 체험 기간 중 인위적인 워터마크나 기능 제한 없음
- **구독 체계**:
  - 단일 연간 구독: 국내 120,000원 + VAT 10% (최종 132,000원) / 글로벌 USD 100/년
  - 월간 구독이나 영구 라이선스는 제공하지 않음
  - 글로벌 결제대행사 Paddle (Merchant of Record)을 통해 처리
- **기기 등록 정책**:
  - 라이선스 1개당 1대 기기 활성화
  - 기기 교체는 연 1회 지원 (구 기기 해제 후 신규 기기 등록)
- **데이터 보존 정책**:
  - 구독 만료 시 신규 영상 분석 및 내보내기만 일시 제한
  - 로컬 드라이브에 저장된 기존 프로젝트 데이터, 데이터베이스, 분석 결과물은 절대 삭제되지 않고 영구 보존됨

## 4. 편집 도구 연동 및 내보내기 사양 (Editorial Export Specifications)
- **자막 파일 (SRT · VTT)**:
  - 촬영 파일마다 자막 파일(SRT·VTT)을 제공합니다.
  - **SRT**: Premiere Pro와 DaVinci Resolve에서 자막 트랙으로 가져올 수 있어 기본 호환 포맷으로 권장합니다.
  - **VTT**: DaVinci Resolve 등 지원하는 편집 프로그램에서 사용할 수 있으며, Premiere Pro 사용자는 SRT를 권장합니다.
- **편집 참고용 마커 (CSV)**:
  - 마커 CSV에는 컷·대사 위치, 색상, 설명, QC 내용을 함께 기록합니다.
  - DaVinci Resolve나 Premiere Pro에서 마커로 가져오는 방법은 프로그램 버전과 CSV 형식에 따라 달라질 수 있으므로, 필요하면 외부 가져오기 도구나 CSV를 타임코드 인덱스로 활용합니다.
