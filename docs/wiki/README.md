# PreviewLog Landing Wiki Memory

이 디렉터리는 PreviewLog 공식 웹사이트(`previewlog.bldnex.com`)의 지속적인 맥락과 결정 사항을 보관하는 위키 메모리입니다.
작업을 시작할 때는 이 문서를 먼저 읽고, 작업이 끝나면 결정·구조·로드맵 문서를 갱신합니다.

## 문서 지도

| 문서 | 역할 |
| --- | --- |
| [context.md](context.md) | 제품 목적·타겟 고객·가격·라이선스·체험판 핵심 정책 |
| [decisions.md](decisions.md) | 이미 합의된 디자인·콘텐츠·기술적 결정 이력 |
| [architecture.md](architecture.md) | 정적 사이트 구조와 호스팅/배포 파이프라인 |
| [roadmap.md](roadmap.md) | 진행 상태 및 다음 개선 과제 |

## 메모리 운영 규칙

- 확정된 정책과 기능 사실은 `context.md` 또는 `decisions.md`에 기록합니다.
- 파일 구조나 동작 방식이 바뀌면 `architecture.md`를 같은 작업에서 갱신합니다.
- 날짜가 중요한 결정에는 `YYYY-MM-DD` 형식을 표기합니다.
- 기획이나 사실에 어긋나는 근거 없는 주장(가짜 고객 후기, 허위 수치 등)은 기록하거나 구현하지 않습니다.
