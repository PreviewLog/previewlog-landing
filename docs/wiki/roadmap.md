### 2026-10-07 디자인 진단 (제안, 미확정)

- 운영 사이트를 데스크톱 1440px 및 모바일 390px 뷰포트에서 확인했습니다. 디자인 구현 및 배포 변경 없이 개선안을 제시했습니다.
- 우선 검토: 목업의 `1시간 영상 → 3분 40초`, `신뢰도 98.4%` 등 수치 근거 확인. 확인 전 성능 근거로 사용하지 않고, 화면 예시 여부를 명시하는 방향을 제안했습니다.
- 시각 방향 제안: 흰색·파란색 중심 페이지에서 전문 영상 도구의 다크 NLE 정체성을 페이지 전반으로 확장하고, 실제 앱 화면 및 HTML/PDF 결과물 예시를 중심에 배치합니다.
- 구성 제안: 반복되는 기능·대상 설명과 섹션 여백을 압축하고, 출시 준비 상태와 알림 등록을 상단에서 명확히 안내합니다.
- 모바일 제안: 목업의 6~8px 보조 텍스트를 축소 표현 대신 핵심 결과 카드로 재구성하고, 등록 영역의 중첩 카드·패딩을 줄입니다.
- 위 항목은 디자인 분석에 따른 제안이며 확정된 디자인 결정이나 완료된 구현이 아닙니다.

### 2026-10-07 기능 소개 문서 기반 개선안 보완 (제안, 미확정)

- 참조: `/Users/macsk/Projects/previewlog/docs/00_business/PREVIEWLOG_FEATURE_OVERVIEW.md`. 문서상 기능을 바탕으로 한 제안이며 앱 구현 검증은 수행하지 않았습니다.
- 핵심 전달 가치: 대표 컷 자동 정리 → 대사·화면·QC를 연결해 검토 → 앱 없는 수신자에게 HTML 공유본 전달.
- 첫 화면은 기존 헤드라인을 유지하고, `컷 요약 / 대사 검토` 보기와 대사 클릭 시 해당 구간 재생을 중심으로 제품 화면을 구성하는 방향을 제안합니다.
- 기능 설명은 자동 장면 감지·중복 컷 묶기, 통합 검색·대사 탐색, 수정·되돌리기, 화면·오디오 QC의 작업 흐름으로 재구성합니다. 다채널 인식·채널별 재전사·클로바노트 전사 교체는 상세 기능으로 배치합니다.
- 결과물은 앱 없이 브라우저로 보는 읽기 전용 HTML을 우선 노출하고, PDF·CSV 편집 참고 목록 및 SRT·VTT 자막을 용도별로 설명합니다.
- 사용자 지시에 따라 프록시–원본 연결(저용량 프록시 검토·원본 읽기 전용 보호 및 선택 컷의 원본 화질 재추출) 소개는 개선안과 향후 랜딩 콘텐츠에서 제외합니다.
- 기능 개요의 CSV 마커 `바로 쓸 수 있는` 표현은 기존 호환성 안내와 차이가 있습니다. 무조건적인 직접 연동을 약속하지 않고 프로그램 버전·CSV 형식에 따른 가져오기 조건을 유지합니다.
- 분석의 로컬 처리와 계정·활성화·업데이트의 인터넷 필요를 구분하며, 근거 없는 처리 시간·정확도 수치는 추가하지 않습니다.
- 구현 순서 제안: 카피 및 주장 정리 → 실제 앱·공유본 에셋 확보 → 첫 화면·결과물 중심 재구성 → 다크 스타일 및 모바일 가독성 정비. 사이트 코드·배포는 변경하지 않았습니다.
