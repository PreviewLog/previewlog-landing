# PreviewLog landing site

PreviewLog 앱 소개와 출시 안내를 위한 정적 랜딩페이지입니다.

## Preview locally

```bash
python3 -m http.server 4187
```

브라우저에서 [http://localhost:4187/site/](http://localhost:4187/site/)를 엽니다.

## Included pages

- `site/index.html` — landing page
- `site/install.html` — installation guide
- `site/requirements.html` — public system requirements
- `site/changelog.html` — release notes placeholder

설치파일, 실제 지원 이메일, 결제·고객 포털은 릴리스 운영 정보가 확정된 뒤 연결합니다.
